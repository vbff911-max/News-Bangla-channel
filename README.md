# সত্যবার্তা – বাংলা নিউজ পোর্টাল

ফাইল: index.html, style.css, script.js, robots.txt

## GitHub Pages-এ চালু করার ধাপ
1. github.com এ নতুন repository খুলুন (Public)।
2. "Add file > Upload files" থেকে সব ফাইল আপলোড করে Commit করুন।
3. Settings > Pages > Source: "Deploy from a branch" > Branch: main, Folder: /(root) > Save।
4. ১-২ মিনিট পর লিংক পাবেন: https://ইউজারনেম.github.io/রিপোর-নাম/
